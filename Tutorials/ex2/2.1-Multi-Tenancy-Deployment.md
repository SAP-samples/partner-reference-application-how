# Deploy Your SAP BTP Multi-Tenant Application

This tutorial guides you through the steps to deploy and configure the multi-tenant sample application (Poetry Slam Manager) in a dedicated SAP BTP provider subaccount.

## Build and Deploy to Cloud Foundry

1. Open a new terminal and log on to SAP BTP Cloud Foundry runtime: 
	1. Run the following command to login. 
        ```
        cf login -a <API endpoint URL> --origin <Origin Key of your Identity Provider>
        ```

	2. Enter the SAP BTP Cloud Foundry runtime API of your environment, for example, `https://api.cf.eu10.hana.ondemand.com`.
	3. Enter your development user and password.
	4. Select the org of the SAP BTP provider subaccount for the application. 
	5. Select the SAP BTP Cloud Foundry runtime space (*app*).

2. Navigate to the root folder of the project.

3. Run the following command to install the npm packages on the root folder.
    ```
    npm install
    ``` 

4. Run the following command to install the npm packages for the *app/poetryslams* subfolder.
    ```
    npm install
    ``` 

5. Run the following command to install the npm packages for the *app/router* subfolder.
    ```
    npm install
    ``` 

6. Run the following command to install the npm packages for the *app/visitors* subfolder.
    ```
    npm install
    ``` 

7. Run the following command to install the npm packages for the *mtx/sidecar* subfolder.
    ```
    npm install
    ``` 

8. Run the following command in the root folder to build the project. The *archive.mtar* is added to the *mta_archives* folder. 
    ```
    npm run build
    ``` 
> Note
> In case of build errors please run **npm update @ui5/cli** in the folders *app/visitors* and *app/poetryslams*

9. To deploy the application, run the following command. 
    ```
    npm run deploy
    ``` 

# Conclusion

You have now successfully deployed the application to the provider subaccount and are ready to [provision tenants of the multi-tenant application to customers](./2.2-Multi-Tenancy-Provisioning.md).
